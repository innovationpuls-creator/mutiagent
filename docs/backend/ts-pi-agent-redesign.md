# OneTree AI 编排网关重构与 Pi 模型配置设计方案

> 文档日期：2026-11-27  
> 适用范围：OneTree（一棵树）AI 编排层迁移至 TypeScript（`LangGraph.js` + `Pi`）及全员个人模型配置功能

---

## 1. 总体架构与职责边界

本次重构采用 **“TypeScript 编排网关 + Python 业务数据核心”** 的双层架构，彻底清退 Python 侧的 `langchain`、`langgraph`、`langchain-openai` 依赖，所有大模型调用、Agent 编排、流式推送与 Token 统计 100% 归口至 TypeScript 编排网关。

### 1.1 技术栈分工

| 层次 | 载体 | 核心技术 | 职责边界 |
|---|---|---|---|
| **宏观状态图编排** | TS 编排网关（新增 `ai-gateway/`） | `@langchain/langgraph` | 定义共享状态、多节点流转、子图并发执行、通过自定义流向前端输出标准 SSE 事件。 |
| **节点内模型与工具循环** | TS 编排网关（`ai-gateway/`） | `@earendil-works/pi-ai`、`@earendil-works/pi-agent-core`、`@sinclair/typebox`（长任务按需引入 `pi-durable`） | 统一多厂商 LLM 流式调用、思考深度控制、多模态输入、原生 Tool Loop、强类型参数校验与自动自修正。 |
| **业务核心与持久化** | Python 后端（现有 `backend/`） | FastAPI + SQLModel + PostgreSQL + Alembic | 登录鉴权（JWT）、PostgreSQL 数据表与迁移、学生级并发锁、业务事务（幂等提交/进度解锁）、教材文档解析与后台 Worker、**向 TS 网关提供内部 REST 数据接口**。 |

### 1.2 核心约束与接入原则

- **数据边界**：TS 编排网关**不直连 PostgreSQL**，所有读写、锁控制与事务一致性统一调用 Python 内部接口。
- **前端协议兼容**：Nginx / Vite 将流式 AI 路由代理至 TS 编排网关；TS 网关复用既有 JWT 鉴权，保持现有前端 SSE 事件名与卡片数据结构兼容，降低前端改造成本。
- **人人用自己的 AI**：全平台采用统一的「个人模型配置」，不设系统兜底或代付额度；学生与管理员均在个人空间配置并使用自己的模型。

## 2. 核心 AI / Agent 业务模块设计（按用户使用顺序）

### 2.1 功能一：入口分流、Supervisor 意图路由与画像采集

- **运行形态**：LangGraph.js 主图（`supervisor` 节点 + `profile_agent` 节点）。
- **入口分流极简化**：
  - 仅保留前端显式协议动作（如章节资源生成触发）的直通分流。
  - 删除原有的自然语言关键词拦截处理器（进度导航、大纲查看、路径查看），改为注册只读查询工具交由 Agent 按需调用。
- **动态工具集门禁（替代 900 行规则引擎）**：
  - 砍掉中文关键词匹配与硬拦截逻辑，保留 3 条核心业务阶段门禁，按学生当前数据库状态动态决定本轮注入给模型的工具列表：
    1. **无完整画像**：仅开放画像追问与画像保存工具。
    2. **有画像、无按年路径**：开放画像更新与课程草案工具。
    3. **有画像且有路径**：开放全量规划、查询、大纲与资源触发工具。
- **画像采集重写（`profile_agent`）**：
  - 节点内采用 Pi 原生工具循环，拆分为「追问卡片工具」与「保存画像工具」。
  - 保留既有 16 字段库表与前端交互卡片契约：核心字段必须向学生确认，次要字段允许在学生未提及或要求快速生成时合理默认，减少多轮追问。
  - 取消本地正则抽取与外层手工修复链：保存工具内做确定性校验（如年级范围、必填项），不通过时直接将错误回传给 Pi 循环在同轮内自修正或转为追问。

### 2.2 功能二：课程草案确认与按年学习路径

- **运行形态**：LangGraph.js 主图（`learning_path_intake_agent` 节点 → `learning_path_agent` 节点）。
- **课程草案节点（四态流转：无草案 → 普通待确认 → 风险待二次确认 → 已确认）**：
  1. **意图决策（Pi 工具循环）**：取消关键词表，明确支持 4 类业务动作——生成/修订草案、确认草案、取消风险修改、仅解答学生疑问（不改动草案状态）。
  2. **教材目录检索与知识缺口**：按学生方向从 Python 内部接口拉取已发布教材大纲摘要（只给目录不给正文）。若修改草案时目标方向暂无教材，**保留当前已有草案不被清空**，仅上报知识缺口给管理员并提示学生继续调整或确认原草案。
  3. **来源绑定校验与自纠**：取消本地模糊打分硬凑小节；若模型绑定了不存在的教材小节，通过 Pi 循环原地自纠（最多 2 次）。
  4. **防误删风险检测（确定性规则）**：对比新草案与已有大纲/已开始学习课程，若存在删除或替换，强制进入“风险待二次确认”态并列出受影响课程。
- **正式学习路径节点（“模型做规划，程序做装配”）**：
  - 草案确认后由 LangGraph 无缝跳转至本节点，同轮完成路径生成。
  - **模型减负**：模型只输出学年总目标、每门课的周期/节奏理由、阶段标题、核心知识点、重难点、验收标准及下一步行动。
  - **确定性装配**：程序严格沿用已确认草案的课程顺序与教材绑定，自动生成标准化节点编号、知识点层级、先修关系边和下游契约，并衔接既有学习进度。
  - **旧大纲清理策略**：保持现有简单策略，刷新该年级学习路径时按年级清空旧课程大纲。

### 2.3 功能三：课程章节大纲

- **运行形态**：LangGraph.js 主图（`course_knowledge_agent` 节点）。
- **确定性大纲骨架构建**：
  - 由程序根据课程绑定的教材小节确定性生成“一级章 + 二级小节”树状骨架与来源映射，彻底杜绝大模型编造教材来源。
  - **超长正文自动拆分**：当单小节绑定的教材正文超过 8000 字时，由大纲骨架构建器**自动按段落/篇幅拆分为多个学生端小节**，不再直接报错中断。
- **中文教学命名与自纠（Pi 节点内调用）**：
  - 模型仅负责输出个性化学习说明与学生端可见的中文标题、简介、核心知识点；校验不合规（漏节点、含英文原标题或内部小节 ID）时原地自纠一次。
- **全年多课受控并发与局部成功**：
  - 一次性生成本年级全部课程大纲时，按 2–3 门受控并发执行，每完成一门即时推送 SSE 进度。
  - 采用**部分成功策略**：已成功生成的课程正常落库保存，仅提示失败课程并支持学生单独补生成。
  - 落库前通过 Python 内部接口加学生锁核验学习路径版本，防止生成期间路径变动导致脏写。

### 2.4 功能四：小节多模态教学资源生成

- **运行形态**：独立的 **LangGraph.js 资源生成子图**（叶茂页按钮点击与聊天框自然语言触发统一进入同一子图，彻底消除双轨维护）。
- **入口门禁与重生成侧重点**：
  - 统一校验当前课程归属、上一章测验解锁状态、教材可见性，并向 Python 后端申请章节级生成锁。
  - **重生成侧重点显式化**：取消在 AI 回复文本中埋隐藏标签（`LEAF_REGEN_PENDING`）的做法，升级为**会话状态里的显式结构化字段**。
- **单小节并行流水线（Fan-out / Fan-in）**：
  - 整章拆为多个小节任务（控制并发 2–3 个小节）。
  - 每个小节内部流程：
    1. **图文生成（Pi 循环）**：严格依据绑定教材正文生成 5 板块文档及视频/动画需求单，不合规则原地自修。
    2. **视频与动画并发执行**：图文通过后，**视频检索节点**（高质量外部检索与链接核验服务，优先保障检索命中质量与精准度）与 **HTML 动画节点**（Pi 生成 + 结构安全校验自修 + 确定性兜底模板）**同时并发**。
    3. **单小节拼装与即时落库**：该小节资源就绪后立即拼装落库并推送 SSE，学生无需等待整章结束即可先阅读已完成小节；同时记录小节阶段检查点，失败重试时自动跳过已通过质量校验的阶段。
- **视频容错策略**：在保证视频检索器高质量的前提下，若某小节确无合格视频，**平稳降级**（正文跳过视频占位并提示暂缺视频），不阻断图文和交互动画的交付。
- **收尾处理**：整章完成后释放章节生成锁，通知 Python 后端执行课程资源质量评分。

### 2.5 功能五：章节测验生成、混合判分与 Forest AI 答疑

- **运行形态**：独立 AI 服务（不进入 LangGraph 主图）。Python 侧继续全权负责章节解锁、题目版本校验、幂等提交与断流恢复快照、进度推进与薄弱点落库；TS 网关仅负责 3 个纯 AI 能力模块。
- **章节出题模块（Pi 结构化输出 + 自纠）**：
  - Python 侧汇总该章下全部二级小节的练习任务、检查标准与知识点清单作为出题上下文。
  - 强约束校验：题型覆盖单选/代码/图片各 1 题、总分严格等于 100 分、单选答案完整、知识点真实属于本章；不合规则原地自修，**取消失败时静默塞通用假题的做法**。
- **混合判分模块（按题型分流 + 程序汇总）**：
  1. **单选题**：纯规则直接比对标准答案（零耗时、零幻觉）。
  2. **代码题**：Pi 文本/推理模型对照检查标准评估逻辑与边界，输出分数与修改建议。
  3. **图片题**：启用**真实多模态视觉判分**，将学生上传的图片连同题目要求送入视觉模型审阅（未传图时按文字说明降级评估）。
  4. **汇总**：由程序严格累加三题得分并判定是否及格，再生成简洁中文总评。
- **Forest AI 答疑模块（Pi 轻量多模态 Agent）**：
  - 支持带图提问与当前测验页多轮追问；挂载只读查阅工具，可按需读取本章小节讲解与绑定教材原文。
  - **教学辅导策略**：在学生**尚未提交或尚未通过测验**前，严格采用**苏格拉底式分步提示**（引导思路、不直接剧透标准答案与完整代码）；提交判分后再展开完整解析。

### 2.6 功能六：成森累计 AI 成长报告与管理端知识库 AI

- **成森累计成长报告（Pi 探索式查证 Agent）**：
  - 不进入 LangGraph 主图，保持三阶段流式反馈（汇总记录 → 查证分析 → 撰写报告 → 完成）。
  - 从“一次性盲选证据”升级为**受控探索式查证**：挂载 3 个只读工具（读测验详情、读章节详情、读教材原文，总调用次数上限锁死 6 次）与 1 个「提交报告」工具。
  - 完整保留 4 条确定性防幻觉校验（证据 ID 真实性、无测验禁写优势、课程归属校验、事实数字出处校验），直接内置于提交工具内，不通过即由 Pi 循环原地修正。
- **管理端知识库隐藏 AI 收口**：
  - 教材解析与后台长任务 Worker（抢锁、租约、心跳）完全保留在 Python 侧不动。
  - 将原藏于 Python 知识库服务中的 **外文教材分段翻译** 与 **公开教材联网搜书** 抽成 TS 网关的两个内部接口；管理员触发时携带本人用户身份，使用**该管理员自己配置的模型**执行。

## 3. 全员个人 Pi 模型配置模块设计

遵循 **“一视同仁，人人用自己的 AI”** 原则：全平台只有一套统一的「个人模型配置」，不区分系统兜底与代付额度；学生端与管理端菜单栏均提供相同能力的「模型配置」入口，各自管理并使用本人的模型配置。

### 3.1 入口与未配置引导

- **顶部菜单栏「模型配置」独立页**：学生端与管理端顶部菜单均新增「模型配置」页面，完整开放 Pi 提供的全部配置能力。
- **工作区快捷切换器**：在全局 AI 对话面板顶部与 Forest AI 答疑栏内提供轻量下拉选择器，支持随时在本人已启用模型间切换，并直接调整 **6 档思考深度（关闭 / 极简 / 低 / 中 / 高 / 极高）**，下一条消息立即生效。
- **未配置统一引导**：任意用户首次触发 AI 功能（对话、生成路径/大纲/资源、测验、成长报告，或管理员搜书/入库翻译）时，若尚未配置可用模型，明确提示并提供一键跳转「模型配置」的入口。

### 3.2 覆盖 Pi 全功能的五大配置能力

1. **Provider 与模型目录（内置 + 自定义）**
   - 直接同步 Pi 内置的主流厂商与模型目录（自带上下文窗口、最大输出长度、视觉/工具/思考能力标签及参考单价）。
   - 支持用户新增任意自定义中转站或本地服务（vLLM、Ollama、定制端点）：配置协议族（OpenAI Chat Completions / OpenAI Responses / Anthropic Messages / Google Native）、Base URL、自定义请求头、能力标签，以及 **Pi 协议兼容项（Compat）**（推理字段格式、系统角色兼容、Token 上限字段等）。
2. **多形式凭证管理与一期 Web OAuth 闭环**
   - **API Key 模式**：加密存储、界面脱敏展示、随时替换或停用。
   - **Web 端 OAuth 授权模式（一期上线）**：
     - 采用**双模式授权引导**：支持 Web 回调的厂商授权后自动跳回换取 Token；仅支持本地回调的厂商提供“复制回调链接 / 粘贴授权码”兜底输入框，覆盖所有 Pi 支持的 OAuth 厂商。
     - **并发续期锁**：Access Token 与 Refresh Token 加密入库；并发任务触发过期刷新时按「用户 + 厂商」加锁单次刷新，防止 Refresh Token 互相顶掉失效。
     - **过期主动提醒**：授权失效时前端弹出带重新登录按钮的明确提示。
3. **Pi 原生推理、生成与缓存参数**
   - 统一控制 6 档思考深度、温度、最大输出长度、单次超时、最大重试次数，以及 Pi 的 Prompt 缓存策略。
4. **场景槽位绑定与高可用回退链**
   - **极简模式（默认）**：用户只需指定 1 个主力模型 + 1 个视觉模型，自动应用到全部场景。
   - **高级模式（按需展开）**：可为不同场景（对话与画像、路径与大纲、图文与动画、测验视觉判分与答疑、成长报告；管理员额外含教材翻译与搜书）分别指定主模型、思考深度及**故障回退链（Fallback Chain）**，主模型限流/超时/5xx 时自动无缝切换备用模型。
   - **能力防呆校验**：如测验图片判分槽位强制校验视觉能力，不满足则禁止绑定。
5. **一键连通性探针与个人用量看板**
   - 保存前或随时触发探针，实测**基础文本、工具调用、视觉图片**三项能力及首字延迟。
   - 承接 Pi 返回的精确统计（输入/输出/缓存命中/推理 Token 与估算费用），展示个人按天与按场景的消耗趋势。

### 3.3 运行时热更新机制

- TS 编排网关按请求动态加载当前用户的生效模型配置，在内存中构建该用户的 Pi 模型与回退链实例（带短周期缓存）。
- 用户在界面保存任意配置变更后，Python 侧落库并通知 TS 网关即时失效该用户缓存，全程无需重启任何服务。

## 4. 阶段一细化设计：目录结构、数据模型与内部接口契约

### 4.1 TS 编排网关模块划分（`ai-gateway/`）

- **入口与协议层**：HTTP / SSE 服务（Hono / Fastify）、JWT 鉴权中间件、SSE 事件适配层（对接既有前端事件协议）。
- **Pi 模型运行时层**：内置与自定义模型注册表、多用户模型解析与回退链执行器、Web OAuth 授权与续期适配器、连通性探针、用量上报器。
- **LangGraph.js 编排层**：
  - 主对话图（`supervisor`、`profile`、`learning_path_intake`、`learning_path`、`course_knowledge`）
  - 资源生成子图（入口门禁、单小节并行流水线：图文 → 视频与动画并发 → 单小节拼装落库）
- **独立 AI 服务层**：章节出题、按题型混合判分（含视觉）、Forest AI 苏格拉底答疑、成森探索式成长报告、知识库翻译与搜书服务。
- **后端客户端层**：调用 Python 内部 REST API 的强类型客户端（统一透传请求 ID 与内部服务鉴权令牌）。

### 4.2 新增个人模型配置数据表（Python / PostgreSQL）

| 表职责 | 核心内容 | 安全与一致性要求 |
|---|---|---|
| **用户 Provider 凭证表** | 用户 ID、Provider 标识、类型（内置/自定义）、协议族、Base URL、自定义请求头、鉴权方式（API Key / OAuth）、加密凭据密文、OAuth 过期时间、启用状态 | 凭据全部应用层加密存储；支持按「用户 + Provider」加行锁做 OAuth 并发刷新。 |
| **用户自定义模型表** | 用户 ID、归属 Provider、模型 ID、展示名称、能力标签（视觉/工具/思考）、上下文/最大输出限制、Pi Compat 兼容参数、参考单价 | 与 Pi 内置目录合并后作为该用户的完整可选模型池。 |
| **用户场景槽位与偏好表** | 用户 ID、默认主力模型、默认视觉模型、默认思考深度、高级模式下的分场景槽位映射与回退链配置、温度/超时/缓存参数 | 保存时触发能力防呆校验，并通知 TS 网关失效对应用户缓存。 |
| **模型调用用量流水表** | 用户 ID、业务场景、Provider、模型 ID、输入/输出/缓存/推理 Token、估算费用、耗时、是否成功、创建时间 | 供个人用量看板按天/按场景聚合统计。 |

### 4.3 Python 内部接口契约清单（供 TS 网关调用）

1. **个人模型配置类**：读取用户完整生效配置（含解密凭据，仅限内网调用）、回写 OAuth 刷新后的加密 Token、记录单次调用用量流水。
2. **对话与学生上下文类**：加载会话历史与显式会话状态字段（含重生成侧重点）、读取/保存画像、读取/更新课程草案、读取/保存按年学习路径、读取/保存课程大纲与单小节资源、读写小节生成检查点、申请/释放章节级生成锁、触发课程质量打分。
3. **知识库与证据类**：按主题检索已发布教材目录摘要与登记知识缺口、按课程拉取已发布教材小节正文与字符数、校验教材学生可见性、读取成长报告总览快照及单条只读证据（测验/章节/教材）。
4. **测验协作类**：读取章节出题上下文、供 Forest AI 查阅本章小节讲解与绑定教材原文。
