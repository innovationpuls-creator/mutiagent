## 1. 目标范围与前置依赖

### 1.1 目标范围
在学生端与管理端菜单栏上线统一的个人「模型配置」页面，完整暴露 Pi 的全部模型配置能力（内置/自定义 Provider、API Key、Web OAuth 登录、Compat 兼容参数、极简/高级槽位与回退链、三项探针测试、个人用量看板）；同时在全局 AI 对话面板与 Forest AI 答疑栏加入「当前模型 + 6 档思考深度」快捷切换器，并落地全站统一的“未配置模型 / OAuth 过期”引导体验。

### 1.2 视觉与交互基线
严格遵循项目现有 `docs/ui-design/` 规范：温暖纸感与圆润容器、哑光质感、清晰层次、支持 `useReducedMotion` 动效降级、兼容 `< 1024px` 移动端与桌面端响应式布局。

## 2. 现有源码盘点与边界约束

1. **学生端导航栏结构**（`frontend/src/components/ui/Navbar.tsx`）
   - 现状：顶部中间为五阶段固定 Tab（萌芽/繁枝/叶茂/成林/成森），右侧头像下拉菜单内现有三项：「个人资料」、「偏好设置 · 暂不可用（disabled）」、「退出登录」。
   - 接入点：在学生端个人下拉菜单中将原禁用占位项替换为可点击的 **「模型配置」**（跳转 `/settings/models`），同时可在顶部或个人菜单头像旁显示未配置红点/状态提示；不破坏五阶段核心导航的视觉平衡与移动端底部五项导航。
2. **管理端菜单栏结构**（`frontend/src/components/layout/AdminLayout.tsx`）
   - 现状：`adminRoutes` 包含 4 项：「账号管理」「人培方案」「数据管理」「知识库」。
   - 接入点：在 `adminRoutes` 新增第 5 项 **「模型配置」**（跳转 `/admin/models`），复用与学生端完全同一套个人模型配置页面组件（管理员额外在高级槽位列表中可见「教材翻译」与「公开教材搜书」两个管理端场景槽位）。
3. **工作区 AI 交互入口**（`frontend/src/components/onboarding/AiGreetingInput.tsx`、`frontend/src/pages/forest/ForestQuizPanels.tsx`）
   - 现状：全局对话面板在 `/sprout`、`/branch`、`/leaf` 悬浮挂载；Forest 答疑栏内嵌于 `/forest/:courseNodeId` 页面。
   - 接入点：两处均在输入框上方或面板顶栏嵌入同一个轻量的 **`ModelQuickSwitcher`** 组件，读取当前用户已启用模型池与默认思考深度，切换时调用 `PATCH /api/model-config/quick-switch` 立即持久化并生效。
4. **权限与路由门禁**（`frontend/src/App.tsx`）
   - 学生访问 `/settings/models` 受学生登录态保护，管理员访问 `/admin/models` 受管理员角色门禁保护；两个页面内部共享同一套业务组件与状态管理。

## 3. 业务模块与页面信息架构设计

### 3.1 「模型配置」独立页（4 个清晰分区）
1. **Provider 与凭证管理区**
   - 展示 Pi 内置厂商卡片 + “新增自定义 Provider / 中转站”入口，每张卡片清晰标注状态（未配置 / API Key 已启用 / OAuth 已授权及到期时间 / 授权已过期）。
   - **API Key 配置抽屉**：输入密钥（回显脱敏掩码）、Base URL（可选覆写）、自定义请求头（键值对）、启用开关。
   - **OAuth 登录弹窗（一期双模式）**：点击“OAuth 登录”后，自动拉起授权页；若为自动回调厂商，等待回调完成并刷新状态；若为本机回调厂商，同屏展示“复制授权链接 + 粘贴回调 URL / 授权码”输入框，一键完成授权。
   - **自定义模型与 Compat 面板**：支持在任意 Provider 下新增/编辑自定义模型，配置模型 ID、展示名、上下文/最大输出、能力标签（视觉/工具/思考）、参考单价，以及可折叠的 **Pi Compat 高级兼容项**。
2. **场景槽位与运行参数区（极简 / 高级双模式）**
   - **极简模式（默认展开，2 分钟上手）**：
     - 只需选择 **「主力模型」**、**「视觉模型」**（自动过滤仅展示具备视觉能力的模型）与 **「默认思考深度（6 档分段控件）」**，自动映射到全部业务场景。
   - **高级模式（按需切换）**：
     - 按业务场景独立配置（对话与画像、课程路径与大纲、小节图文与动画、测验视觉判分与答疑、成森成长报告；管理员额外展示教材翻译、公开教材搜书）。
     - 每个场景支持单独选模型、单独调思考深度、拖拽或增删**备用回退链**，并配置温度、单次超时、重试次数与 Prompt 缓存开关。
     - **前端即时防呆**：无视觉能力模型在视觉槽位中置灰并标注“不支持图片输入”。
3. **一键三项连通性探针区**
   - 在 Provider 抽屉与主模型卡片均提供「测试连接」按钮，调用 `/api/ai/models/probe`，直观展示三项子结果徽章（文本 ✔/✘、工具调用 ✔/✘、视觉理解 ✔/✘/未声明）与首字延迟（ms）。
4. **个人用量与费用看板区**
   - 汇总展示今日/近 7 天/近 30 天的总调用次数、成功率、输入/输出/缓存命中/推理 Token 数与估算费用，支持按业务场景分布查看。

### 3.2 工作区快捷切换器（`ModelQuickSwitcher`）
- 紧凑展示当前生效的模型名 + 当前思考深度徽章（如 `中思考`）。
- 点击展开轻量浮层：上半区切换本人已启用的模型（带视觉/思考小图标），下半区为 6 档思考深度分段选择（关闭 / 极简 / 低 / 中 / 高 / 极高），底部附“管理更多模型 →”快捷入口。

### 3.3 全站统一“未配置 / 过期”引导机制
- 在前端统一 API/SSE 错误拦截层识别 M1 定义的 `MODEL_NOT_CONFIGURED` 与 `MODEL_OAUTH_EXPIRED`：
  - 捕获 `MODEL_NOT_CONFIGURED`：在当前对话框或页面内展示温和引导卡片，说明“请先配置你的个人 AI 模型”，提供直达 `/settings/models`（学生）或 `/admin/models`（管理员）的按钮。
  - 捕获 `MODEL_OAUTH_EXPIRED`：明确指出具体失效的 Provider 名称，提供一键跳转至对应厂商重新登录的按钮。

## 4. API 客户端与状态同步

- 执行 `npm run gen:api` 同步 M2 新增的后端模型配置接口类型至 `frontend/openapi.json` 与 `frontend/src/types/api.ts`。
- 新增 `frontend/src/api/modelConfig.ts` 与 `ModelConfigContext`（登录态就绪后加载轻量个人配置摘要，供快捷切换器与红点提醒共享，避免每个页面重复请求）。

---

## 5. 风险点与缓解策略

1. **配置项过多导致新手望而却步**：默认展示「极简模式」，把 Compat、自定义请求头、分场景回退链收进折叠区与「高级模式」，做到“新手 30 秒配好，极客全部可调”。
2. **移动端（< 1024px）表单与下拉溢出**：抽屉与快捷切换器复用项目既有 `useDialogAccessibility` 与安全区/动态视口约束，保证键盘可达、焦点恢复与小屏不遮挡导航栏。
