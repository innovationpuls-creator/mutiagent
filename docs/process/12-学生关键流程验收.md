# 学生关键流程验收记录

验收日期：2026-10-10。范围为登录、首页、课程目录与阅读、章节测验、结果恢复及继续学习，不包含管理端。

## 实现范围

- A：五阶段任务名称常显，Leaf 和 Forest 提供真实目录；目录合并学习路径与匹配人培课程，沿用服务端访问规则。学生登录直接进入首页，继续学习进入当前课程；阅读位置按用户和课程保存，URL 有效章节优先。画像采集由学生主动发起并恢复既有会话，个人菜单进入画像详情。
- B：原生 IndexedDB 隔离用户、课程、章节、测验及题目版本，保存三类答案、Blob 图片、题号及修订号。事务成功后显示已保存；未保存离开有明确选择，多窗口冲突停止覆盖。提交快照落盘后才锁定答案和发送，失败可编辑重试；待确认提交刷新后仅查询，原样重试复用 UUID。
- 接口与数据库：权威画像状态、只读章节进度、完整题目 SHA256 版本、成对可选提交标识、本人提交查询及精确结果快照。结果弹层复用生成的成长接口类型，课程完成数按课程状态计数，通过章节数来自章节进度，避免旧字段空白或混用统计口径。迁移保留历史版本为空。批改期间不持锁，最终 User → ChapterQuiz 短事务原子提交；首次通过且课程仍为当前课程才推进实际年度路径。生成和路径替换协调锁内重新校验，过期章节题目及过期路径大纲不落库。
- C：当前课程在画像详情前呈现；小于 1024px 为单列和底部五项导航，内容使用独立滚动区域。安全区、动态视口和软键盘模拟测试覆盖答案与提交按钮。目录及 AI 可收起，原生按钮、输入标签、弹层关闭与焦点恢复、reduced motion 均纳入学生流程。

## 复现

后端测试使用独立 PostgreSQL 数据库并设置 DATABASE_URL。不要指向业务数据库，测试会建立和清理 test_* schema。

```bash
cd frontend
npm test
npm run build
npm run e2e -- student-flow.spec.ts
ONETREE_STUDENT_E2E_DATABASE_URL=postgresql://user@127.0.0.1:5432/onetree_student_test npm run e2e:student:integration
```

真实 API 浏览器夹具强制要求显式设置独立的 *_test 数据库地址，在该库新建独立 schema；服务使用 8001 端口。标准 E2E 不包含此夹具，真实 API 测试通过单独命令执行。
